# WeSpeak plugins

Plugins for hotel teams using WeSpeak with ChatGPT or Claude. Each bundle combines operating guidance with a connection to the WeSpeak customer MCP server.

A WeSpeak account with MCP access enabled is required. Sign in with your own WeSpeak account; available tools follow your account permissions.

- [Claude bundle and installation guide](claude/README.md)
- [ChatGPT bundle and installation guide](openai/README.md)

The bundles contain plugin instructions, metadata, and icons. The WeSpeak service is hosted separately. See each bundle's guide for installation and connection requirements; this repository alone does not indicate directory approval or publication.
